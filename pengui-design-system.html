Ground rules

The 4 things to not re-litigate

Background = warm creamNever pure white or a cool off-white. --background is the base for every section; alternate with bg-secondary/25 for contrast between adjacent sections.
Dark cards okay, dark sections notA card/component can use a dark surface. A full section background should not — use .color-block instead for a "livelier" surface.
Headings = Lora, body = GeistEvery h1/h2 uses font-heading (Lora). Body copy, buttons and UI text use the default sans (Geist) — never mix in another family.
One hero size, one section sizePage-hero h1 is always the "Hero" row below. Every in-page section h2 is always the "Section" row. No one-off pixel sizes.
Titles: plain black for nowNo color highlights inside title text (no teal/indigo/lime emphasis words) until the palette direction is decided. Eyebrows stay teal — that rule hasn't changed.
Footer is not whiteFooter uses bg-secondary/25, same as an alternating section — not bg-card.
