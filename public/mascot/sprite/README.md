# Pengui Web Mascot

Animation-ready transparent PNG sprite sheets extracted from the supplied
Pengui pixel-art sheet.

Animations:
- idle — 4 frames
- blink — 3 frames
- wave — 4 frames
- walk — 8 frames
- thinking — 4 frames
- sleep — 4 frames

All assets use transparent RGBA PNGs and should be rendered with
`image-rendering: pixelated` so the pixel art stays crisp.

The original sheet included glow/background effects; these have been
suppressed as part of the extraction. The animations are intentionally
simple first-pass loops so they can be integrated into a web mascot system.
